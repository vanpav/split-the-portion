# Цикл задач из GitHub issues

Claude раз в 10 минут проверяет открытые issues в `vanpav/split-the-portion` и сам делает по ним PR.

## Как работает

- Берутся **только** issues от `ksushunchik` и `vanpav`. Задачи от других людей не выполняются ни при каких условиях — Claude только упоминает их в чате.
- Задача берётся, если в тексте issue (или в комментарии автора) есть `@claude`.
- Задачи с меткой `research` — исследования: цикл их не берёт, даже с `@claude`, и не спрашивает про упоминание. Их начинают вручную, в обычной сессии.
- Если `ksushunchik` забыла `@claude`, Claude один раз спросит в комментарии. Ответ с `@claude` — сигнал начинать.
- На каждую задачу запускается отдельный агент `issue-worker` (по умолчанию medium effort, см. ниже) в своём worktree: метка типа, ветка `<тип>/<N>-<slug>`, код, `pnpm lint && pnpm test && pnpm build`, PR с `Closes #N`.
- Ревьюер PR — автор issue и `vanpav`. PR открываются от аккаунта `vanpav`, а GitHub не даёт запросить ревью у автора PR, поэтому `vanpav` ставится ассигни.
- Взятая задача помечается комментарием «Взял в работу (effort: …)» — повторно её не берут.

Пошаговая процедура одной проверки — [.claude/commands/poll-issues.md](../.claude/commands/poll-issues.md).

## Уровень effort

По умолчанию агент думает на уровне **medium**. Для приоритетной или сложной задачи сразу после `@claude` можно написать уровень повыше:

| Пишем | Агент | Effort |
|---|---|---|
| `@claude` | `issue-worker` | medium |
| `@claude high` | `issue-worker-high` | high |
| `@claude xhigh` | `issue-worker-xhigh` | xhigh |
| `@claude max` | `issue-worker-max` | max |

- Уровень — первое слово сразу после `@claude`, регистр не важен. Любое другое слово — обычный текст задачи, тогда medium.
- Работает и в теле issue, и в комментарии-ответе: `@claude high, берём`.
- Если упоминаний несколько и уровни разные, берётся самый высокий.
- Уровень читается один раз, когда задачу берут. У уже взятой задачи он не меняется.
- Чем выше уровень, тем дольше и дороже работает агент. `max` — для самого важного.

## Запуск

Открыть сессию Claude Code в папке проекта (desktop-приложение или `claude` в терминале) и написать:

```
/loop 10m /poll-issues
```

Цикл живёт, пока открыта сессия. Остановить — сказать «останови loop» (или закрыть сессию).

Нужно: `gh` авторизован как `vanpav` (`gh auth status`), агенты `~/.claude/agents/issue-worker.md`, `issue-worker-high.md`, `issue-worker-xhigh.md`, `issue-worker-max.md` на месте.
