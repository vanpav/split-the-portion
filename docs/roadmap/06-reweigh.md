# 06 — Остаток и перевзвешивание

## Цель
Сценарий «доедаем завтра»: перевзвесить остаток, получить k остатка и считать новые порции от нового веса (SPEC §4.3, пример 3). Расчёт этапов уже есть в домене с этапа 01, здесь — только UI.

## Зависимости
05.

## Задачи
- [x] Кнопка «Перевзвесить остаток» (неактивна, если остаток ≤ 0) → `addReweighing` с текущей датой; режим и тара по умолчанию — как в прошлом взвешивании.
- [x] `WeighingSection` показывает все взвешивания: прошлые — свёрнутой строкой («Этап 1 · вчера · 560 г · k 2,8»), последнее — развёрнуто для ввода.
- [x] Для этапов ≥ 2: «Остаток = 120 г сырого · k 2,58» (для составного — «k остатка»).
- [x] Порции прошлых этапов — свёрнутым блоком с итогом, можно развернуть и отредактировать.
- [x] Новые порции создаются на последнем взвешивании; сверка и «Остаток» — против остатка текущего этапа.
- [x] Удаление последнего перевзвешивания (если ошиблись) — порции этого этапа удаляются с подтверждением (SPEC §4.3 п. 5).
- [x] Строка списка готовок: «остаток N г» для готовок с ненулевым остатком.

## Definition of Done
- Пример 3 руками: гречка из примера 1, только Аня 80 → «в кастрюле 336 г = 120 г сырого» → перевзвесить 310 → «k 2,58» → порция 155 готового → «60 г сырого», «распределено 60 из 120».
- Правка порции Ани на этапе 1 честно меняет цифры этапа 2.
- lint/test/build проходят; 375 px и десктоп без поломок вёрстки.

## Способ проверки
- Пройти DoD на 375 px и на десктопе, перезагрузить страницу в середине — состояние этапов сохраняется.
- Составное блюдо: суп, порция 395, перевзвесить остаток 2600 → k остатка и состав новой порции считаются от нового веса.
