# 03 — Настройки: справочник тары и состав по умолчанию

## Цель
Экран `#/settings`: пользователь заводит посуду с весом и имена людей, с которыми обычно готовит.

## Зависимости
02.

## Задачи
- [x] Секция «Тара» (`Card`, `Input`, `Button`): список (название, вес), добавление строкой внизу (Enter = добавить, фокус возвращается в название), редактирование на месте, удаление с тостом «Отменить» (`Sonner`, 5 с).
- [x] Валидация тары: непустое название, вес > 0 (`isValidTareGrams` в домене + тест, `NumberField.validate`).
- [x] Секция «Состав по умолчанию»: список имён, «+ Человек», «×», пустые имена при сохранении отбрасываются.
- [x] Подпись: состав применяется к новым готовкам.
- [x] Проверить, что `createCooking` (этап 02) действительно берёт актуальный состав.

## Файлы
`src/screens/Settings/**`, при необходимости `src/store/store.ts` (действия `upsertTare`, `deleteTare`, `setDefaultPeople`).

## Definition of Done
- Тара и состав сохраняются и переживают перезагрузку.
- Новая готовка открывается с людьми из состава; уже существующие готовки не меняются.
- Удаление тары не ломает ничего (взвешиваний ещё нет, снимок появится в 04).
- lint/test/build проходят.

## Способ проверки
- 375 px: добавить «Кастрюля 3 л — 850», «Сковорода 28 — 1120», переименовать, удалить одну; добавить «Аня», «Борис» → создать готовку → в ней две порции с этими именами.
- Убрать «Борис» из состава → старая готовка по-прежнему с Борисом, новая — без него.
- Десктоп: одна колонка по центру, поля удобного размера.
