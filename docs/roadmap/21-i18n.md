# 21 — Языки интерфейса

Статус: 21.1 код готов · 2026-10-07. 21.2 — не начат.

## Цель
Интерфейс на английском (по умолчанию), русском и испанском. Язык определяется по устройству, его можно сменить в настройках. Переводим только интерфейс: популярные блюда и фразовый ввод пока русские, но каждому языку потом — свои пресеты.

## Зависимости
18 (тур), 20 (популярные блюда).

## Решения
- i18next + react-i18next + i18next-browser-languagedetector (ARCHITECTURE §2, §11). Согласовано 2026-10-07; подходит и для будущей обёртки в сторы (WebView).
- Два шага: 21.1 — инфраструктура и вынос русских строк, приложение остаётся русским; 21.2 — переводы, автоопределение, выбор языка.
- Domain без языка: форматтеры принимают локаль, тексты собирает UI, вместо «Без названия» домен отдаёт пустую строку.
- Выбор языка хранится как тема — в `localStorage` устройства, не в сторе: читается до первого рендера, язык не мигает. Форма хранимых данных не меняется, миграции нет.
