# 05 — Порции

## Цель
Главный результат приложения: порции по людям в сыром или готовом весе с показом в обоих, сверка суммы, кнопка «Остаток», остаток в кастрюле, деление на N равных, порция от ингредиента, копирование текста для трекера. После этого этапа MVP закрывает сценарии 1 и 2.

## Зависимости
04.

## Задачи
- [x] `shadcn add select collapsible dialog textarea`.
- [x] `PortionsSection` + `PortionRow`: имя (редактируемое), `NumberField`, переключатель базы («сырой» / «готовый»; в составном блюде — «готовый», «сырой: <ингредиент>» только для учитываемых), второе значение справа/снизу.
- [x] База по умолчанию для новой строки: один учитываемый ингредиент → сырой; составное → готовый (`basis: 'default'`, миграция v1 → v2).
- [x] Для составного блюда под строкой — состав порции в сыром весе по ингредиентам («< 1 г» для крошечных).
- [x] «+ Человек», «×» у строки.
- [x] Плашка сверки: ok / incomplete (нейтрально) / under / over (красным, с разницей), текст по UX §6.
- [x] Кнопка «Остаток» у последней строки (условия — SPEC §5).
- [x] «В кастрюле: N г готового = M г сырого» (для составного — готовый + раскрываемый состав).
- [x] «Разделить на N»: результат `splitEqual`, у каждой порции раскрываемый состав.
- [x] `CopyButton`: Clipboard API, при ошибке — `Dialog` с `Textarea` и выделенным текстом; тост «Скопировано» (`Sonner`).
- [x] Порция с исчезнувшей базой (ингредиент удалён или исключён) — подсветка «выберите, в чём вводить».
- [x] Без готового веса: сырые значения работают, готовые — «—», подсказка взвесить блюдо.
- [x] Десктоп: правая колонка «Порции» sticky.

- 1.1: Аня 80 → 224, Борис 120 → 336, сверка ok, в кастрюле 0.
- 1.2: «не распределено 20 г» красным; 1.3: «перебор 10 г» красным.
- 1.4: порция 250 готового → 89 сырого.
- 1.6: Аня 80, «Остаток» у Бориса → 120, сверка ok.
- 2.1: 395 → курица 75, картофель 50, морковь 20, лук 15, рис 10; копирование даёт 5 строк без воды и соли.
