# 14 — Группы: общий учёт, приглашение кодом, группа по умолчанию

## Цель
Ваня и Ксюша ведут учёт вместе: одни блюда, одна история готовок, общая тара, компании и «Убрать человека». Ваня зовёт Ксюшу кодом или ссылкой, Ксюша вступает в его группу и делает её группой по умолчанию — теперь при запуске сразу открывается общая. Человек может состоять в нескольких группах и переключаться между ними; без сети доступна любая из них.

## Зависимости
13.

## Решения пользователя
- Приглашение — код из 8 символов и ссылка с ним; отправляются через мессенджер, писем не нужно.
- В группе общее всё, что хранится: блюда, готовки, тара, компании, составы, «Убрать человека». Тема («Оформление») остаётся настройкой устройства.
- Группа по умолчанию открывается при запуске; переключение на другую её не меняет.

## Задачи

**Сервер**
- [ ] `worker/migrations/0003_invites.sql` — `group_invite(code PRIMARY KEY, group_id, created_by, created_at, expires_at, revoked)`.
- [ ] `worker/invites.ts`:
  - `POST /api/groups/:id/invites` — участник группы получает `{ code, url, expiresAt }`. Код — 8 символов `customAlphabet` из nanoid без похожих (`0/O`, `1/I/l`), живёт 7 дней, по одному коду могут вступить несколько человек. Действующий код группы переиспользуется, а не плодится;
  - `GET /api/invites/:code` → `{ groupName, invitedBy }` или 404 «Код не найден или устарел»;
  - `POST /api/invites/:code/accept` → `auth.api.addMember({ userId, organizationId, role: 'member' })`. Уже в группе — 200 без изменений. Ограничение частоты: перебирать коды нельзя;
  - `DELETE /api/groups/:id/invites/:code` — владелец отзывает код.
- [ ] `PUT /api/me/default-group { groupId }` — только группа, где человек состоит.
- [ ] Выход и удаление участника — встроенные `organization.leave` и `organization.removeMember` (убирает только владелец). Из группы, где ты единственный владелец, выйти нельзя («Личная» в том числе) — сервер отвечает 400.
- [ ] Переименование группы — `organization.update`, любой участник.
- [ ] `/api/me` отдаёт группы с участниками (имя — почта до `@`) и ролью.

**Клиент**
- [ ] Стор аккаунта: `groups` с участниками, `activeGroupId` (что открыто сейчас) отдельно от `defaultGroupId` (что открывать при запуске). Обновляется из `/api/me` при запуске и при возврате на экран.
- [ ] Синхронизация всех групп пользователя, а не только открытой: фоном, по очереди, у каждой свой outbox и `cursor`. Без сети открывается любая группа, которую устройство уже видело. Группа, из которой человек вышел или его убрали (403), удаляется с устройства с тостом «Вы больше не в группе „…“».
- [ ] Переключение группы — «Открыть группу» из ARCHITECTURE §5.2; калькулятор и экраны сбрасываются на список блюд (`navigate('/')`).
- [ ] Настройки → новый подраздел «Группа» (`#/settings/group`, после «Аккаунта»), показывается только после входа:
  - выбор группы (`Select`, если групп больше одной) и звёздочка «Открывать при запуске» у группы по умолчанию;
  - название группы, правится на месте;
  - участники: почта и «владелец»; владелец может убрать участника удержанием × (как людей в компании, `HoldButton`);
  - «Пригласить» → код крупно, ссылка, «Копировать» (`CopyButton`) и «Поделиться» (`navigator.share`, если есть), «Действует до 13 окт.»; владелец — «Отозвать»;
  - «Вступить по коду» → `Dialog` с полем кода (8 символов; показывается как `K7MR-Q2XD`, при вводе дефис, пробелы и регистр не важны; `autocapitalize="characters"`);
  - «Выйти из группы» → `AlertDialog`; для «Личной» кнопки нет.
- [ ] Маршрут `#/join/:code`:
  - не вошли → «Войдите, чтобы вступить в группу „…“» → `#/account`, после входа — обратно;
  - вошли → «Вступить в группу „Ванина кухня“? Пригласил: vanya» → «Вступить»;
  - после вступления — «Открывать эту группу при запуске?» («Да», по умолчанию / «Нет»), группа открывается.
- [ ] Ссылка из мессенджера на iPhone открывается в Safari, а не в установленном приложении (iOS не передаёт ссылки в PWA). Поэтому экран `#/join/:code` в Safari, если приложение не запущено как standalone (`matchMedia('(display-mode: standalone)')`), крупно показывает код: «Если приложение уже на экране „Домой“ — откройте его: Настройки → Группа → Вступить по коду». Вступить прямо в Safari тоже можно.
- [ ] Список блюд: если групп больше одной, под заголовком мелко название открытой группы, тап → Настройки → «Группа».
- [ ] Документы: ARCHITECTURE §6 (маршруты, экраны), §9 (API групп и приглашений); SPEC §2 («Группа», «Группа по умолчанию»), §13; UX — поток «П6. Позвать Ксюшу в группу», экраны «Группа» и «Вступить», словарь.

## Definition of Done
- Ваня приглашает, Ксюша вступает по коду и по ссылке; у неё появляются Ванины блюда, тара и компании; правки каждого видны другому.
- Группа по умолчанию открывается при запуске, в том числе без сети; переключение на другую группу не меняет группу по умолчанию.
- Выход из группы и удаление участника убирают группу с его устройства; «Личную» покинуть нельзя.
- Чужой или устаревший код — понятная ошибка; перебор кодов упирается в ограничение частоты.
- `pnpm lint && pnpm test && pnpm build` проходят.

## Способ проверки
- Chrome — Ваня, Safari — Ксюша, оба вошли. Ваня: Настройки → «Группа» → «Пригласить» → код. Ксюша: «Вступить по коду» → «Вступить» → «Открывать при запуске: Да» → видит Ванины блюда, тару «Кастрюля 850 г» и компанию «Ваня и Ксюша».
- Ксюша варит макароны, как в проверке этапа 09: 130 г сухого, 1162 г с кастрюлей 850 г, компания 70 : 60 → Ваня 168 г, Ксюша 144 г → «Сохранить» → у Вани в «Истории» та же готовка с теми же цифрами.
- Ксюша перезагружает без сети → открылась Ванина группа. Переключилась на «Личную» → перезагрузка → снова Ванина (по умолчанию).
- Ссылка `#/join/<код>` в новом окне без входа → вход → вступление. Устаревший код (`expires_at` в прошлом через `d1 execute --local`) → «Код не найден или устарел».
- Ваня убирает Ксюшу удержанием × → у Ксюши тост «Вы больше не в группе…», открылась «Личная».
- iPhone (установленное приложение): ссылка из Telegram открывается в Safari → на экране код → в приложении «Вступить по коду» → вступила.
- 375 px и десктоп: код читается крупно, без горизонтальной прокрутки; консоль чистая.
