# 14 — Группы: общий учёт, приглашение кодом, группа по умолчанию

## Цель
Ваня и Ксюша ведут учёт вместе: одни блюда, одна история готовок, общая тара, компании и «Убрать человека». Ваня зовёт Ксюшу кодом или ссылкой, Ксюша вступает в его группу и делает её группой по умолчанию — теперь при запуске сразу открывается общая. Человек может состоять в нескольких группах и переключаться между ними; без сети доступна любая из них.

## Зависимости
13.

## Решения пользователя
- Приглашение — код из 8 символов и ссылка с ним; отправляются через мессенджер, писем не нужно.
- В группе общее всё, что хранится: блюда, готовки, тара, компании, составы, «Убрать человека». Тема («Оформление») остаётся настройкой устройства.
- Группа по умолчанию открывается при запуске; переключение на другую её не меняет.

## Definition of Done
- Ваня приглашает, Ксюша вступает по коду и по ссылке; у неё появляются Ванины блюда, тара и компании; правки каждого видны другому.
- Группа по умолчанию открывается при запуске, в том числе без сети; переключение на другую группу не меняет группу по умолчанию.
- Выход из группы и удаление участника убирают группу с его устройства; «Личную» покинуть нельзя.
- Чужой или устаревший код — понятная ошибка; перебор кодов упирается в ограничение частоты.
- `pnpm lint && pnpm test && pnpm build` проходят.

## Способ проверки
- Chrome — Ваня, Safari — Ксюша, оба вошли. Ваня: Настройки → «Группа» → «Пригласить» → код. Ксюша: «Вступить по коду» → «Вступить» → «Открывать при запуске: Да» → видит Ванины блюда, тару «Кастрюля 850 г» и компанию «Ваня и Ксюша».
- Ксюша варит макароны, как в проверке этапа 09: 130 г сухого, 1162 г с кастрюлей 850 г, компания 70 : 60 → Ваня 168 г, Ксюша 144 г → «Сохранить» → у Вани в «Истории» та же готовка с теми же цифрами.
- Ксюша перезагружает без сети → открылась Ванина группа. Переключилась на «Личную» → перезагрузка → снова Ванина (по умолчанию).
- Ссылка `#/join/<код>` в новом окне без входа → вход → вступление. Устаревший код (`expires_at` в прошлом через `d1 execute --local`) → «Код не найден или устарел».
- Ваня убирает Ксюшу удержанием × → у Ксюши тост «Вы больше не в группе…», открылась «Личная».
- iPhone (установленное приложение): ссылка из Telegram открывается в Safari → на экране код → в приложении «Вступить по коду» → вступила.
- 375 px и десктоп: код читается крупно, без горизонтальной прокрутки; консоль чистая.
