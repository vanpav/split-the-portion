# 18 — Подсказки для новых

Статус: в работе · 2026-10-07. Макеты — [docs/mockups/onboarding-hints.html](../mockups/onboarding-hints.html) (открыть файлом в браузере).

## Цель
Человек открыл приложение впервые и за полминуты понял главный цикл: ввести готовый вес → увидеть, сколько положить каждому → скопировать сухой вес в трекер. Сначала — приветственный экран: что это за приложение и зачем аккаунт. Потом — короткий тур по калькулятору. Всё пропускается одним тапом, тур возвращается в настройках. Тем, кто уже пользуется, они не мешают.

## Зависимости
15–17. Сервер не нужен: что показано — настройка устройства.

## Что непонятно новому человеку
- Какой вес куда: «Сухой» и «Готовый» стоят рядом, а вводить обычно нужно только готовый.
- Тара спрятана в тихой строке «Без тары ⌄». Без неё в готовый вес попадает кастрюля, и k выходит странным.
- «Свой состав · 0» и «+ Имя» не говорят, что будет дальше. Что границу на полосе долей можно тянуть, тоже не видно.
- Жесты не видны: свайп строки вправо — копировать для трекера, влево — убрать.
- Что чипы в шапке — это блюда, а поиск добавляет популярные блюда с обычным весом.
- Зачем аккаунт и что будет без него. На iPhone данные из Safari не переезжают в приложение на экране «Домой» (UX П5).

## Решения (2026-10-07)
Варианты вида — в макетах, раздел 1.

1. **Тур с затемнением (вид A)** при первом открытии калькулятора, тот же на телефоне и на десктопе. Шаги:
   1. плитки «Сухой | Готовый» (у составного — «Сырой | Готовый»);
   2. тара;
   3. «Кто ест» — без людей поле «+ Имя», с людьми полоса долей;
   4. полка блюд, кнопка «Готово».
2. **Подсказок по месту нет.** Карточки в потоке (вид C) «Скопировать для трекера» и «Добавьте на экран „Домой“» сделали, посмотрели и убрали (2026-10-07): не понравились. Остаётся только тур.
3. **«Пропустить» выключает подсказки**. Появляется тост «Подсказки выключены» с кнопкой «Вернуть»: тур продолжится с того же шага. Esc — то же, что «Пропустить».
4. **Вернуть подсказки** — Настройки → «Оформление» → «Подсказки»: «Показывать | Не показывать» и «Показать заново».
5. **Приветственный экран (вид D)** `#/welcome` — новый, по просьбе пользователя:
   - Показывается вместо пустого списка блюд, когда на устройстве нет блюд и приветствие ещё не пройдено.
   - Три экрана о приложении, у каждого простая анимация из логотипа: ланчбоксы падают в стопку, плитки весов, полоса долей.
   - Четвёртый экран — аккаунт: что даёт аккаунт и что будет без него. Кнопки «Создать аккаунт» (ведёт на регистрацию `#/account?tab=sign-up`), «Без аккаунта» (на пустой список блюд) и ссылка «Уже есть аккаунт? Войти».
   - Кто уже вошёл, видит три экрана и «Начать».
   - «Пропустить» в шапке — на каждом шаге, и на экране аккаунта тоже: с любого шага сразу в приложение без аккаунта.
   - При «уменьшить движение» анимаций нет.
   - Шаги листаются свайпом на сенсорном экране (влево — дальше, вправо — назад), на десктопе — кликом по точкам шагов и ← / → (2026-10-07).

## Правила показа
- **Тур** начинается через полсекунды после открытия калькулятора, когда переход экрана закончился и сверху нет тостов. На сенсорном экране тур ждёт ещё и пока закроется клавиатура.
- **Тап по затемнению** — «Далее». Выделенный элемент во время тура не нажимается (`disableActiveInteraction`).
- **Уход с экрана** во время тура (системный «назад», ссылка) закрывает его. Новых записей в истории тур не добавляет. При следующем открытии калькулятора он продолжится с того же шага.
- **Цвета.** Тур — основного цвета и нейтральный. Цвета крышек — только у людей и в иллюстрациях логотипа (DESIGN.md).
- **Кто уже пользуется**, подсказок не видит: если при первом запуске новой версии на устройстве уже есть блюда, приветствие и тур считаются пройденными. Посмотреть их можно через «Показать заново».
- **Хранение** — настройки устройства (`prefs.ts`, как «Доли» и тема): не синхронизируются, не попадают в копию данных. На втором телефоне тур покажется ещё раз — один раз.

- **375 px, чистый origin:**
  - `#/` → приветствие, 4 экрана, анимации; «Без аккаунта» → пустой список блюд.
  - «Популярные блюда» → калькулятор «Гречки» → тур, 4 шага → «Готово» → перезагрузка → тура нет.
- **Другой чистый origin:** приветствие → «Создать аккаунт» → открыта вкладка «Создать аккаунт».
- **«Пропустить»:** шаг 2 → «Пропустить» → тост «Подсказки выключены · Вернуть». «Вернуть» — тур с шага 2. Перезагрузка после «Пропустить» — тура нет; «Показать заново» в «Оформлении» — тур с начала.
- **Тур и «назад»:** шаг 3 → системный «назад» → тур закрыт. Снова калькулятор — тур с шага 3.
- **Тёмная тема, «уменьшить движение»** (без анимаций), **1280 px** (тот же тур, Esc — «Пропустить», ← / → листают).
