# 09 — Блюда-рецепты, компании и быстрая готовка

## Цель
Разделить настройку и готовку (SPEC §3а). Блюдо настраивается один раз и сохраняется явной кнопкой «Создать». У плиты нужно ввести две цифры: сухой вес (подставлен из рецепта) и вес после готовки. Блюдо делится между людьми выбранной компании по долям. Остальное свёрнуто в «Подробнее».

## Решения пользователя
- Делим по долям в компании («Ваня 70, Ксюша 60»); на сегодня любому можно задать свою порцию в граммах.
- Сухой вес в новой готовке — обычный из рецепта.
- Старые готовки при обновлении удаляются (прототип), тара сохраняется, состав по умолчанию становится компанией.
- Вес после готовки вводится каждый раз и стоит на виду.

## Проверено
На 375 px и 1280 px. Создание компании и простого блюда; «Готовить» → 130 г, 1162 г с кастрюлей 850 → Ваня 168 г, Ксюша 144 г. Сухой вес 150 → 194 / 166, рецепт остался 130. «С тёщей» → 133 / 114 / 114. Ване своя порция 50 г сухого → 120 г, Ксюше остальное. «Составное на основе» → «По-флотски» (макароны 130, фарш 300) → состав у каждого. Перезагрузка сохраняет готовку, консоль чистая.

## Доработки после ревью

- [x] «Готовить» открывает экран старта; готовка записывается только по «Старт».
- [x] Новое блюдо по умолчанию «Без тары».

## Доработка: компании полосой долей (#5)
- [x] В настройках компания правится как «Кто ест» в калькуляторе: полоса долей (границы, «− Ваня +», «Поровну») без «На завтра» и «г | %», × удержанием, поле «+ Имя».
- [x] Новая компания открывается пустой, фокус в «+ Имя»; без названия компания зовётся по людям и в выборе «Кто ест».
Проверено на 375 px и 1280 px: «+ Компания» → Ваня, Ксюша → 50 : 50, «+» ×4 → 54 : 46, граница → 70 : 30, Тёща → 47 : 20 : 33, «Поровну» → 34 : 33 : 33; перезагрузка сохраняет; в калькуляторе «На завтра» и «г | %» на месте.
