# 04 — Готовка: ингредиенты и взвешивание после готовки

## Цель
На экране готовки работают секции «Ингредиенты» и «После готовки»: пользователь вводит сырые веса, взвешивает блюдо с тарой или без и видит вес без тары и k.

## Зависимости
02, 03.

## Задачи
- [x] Каркас экрана: поле «Название» (пусто — автоназвание из имён учитываемых ингредиентов, видно в плейсхолдере), раскладка одна колонка / две колонки от `lg` (1024 px).
- [x] `shadcn add checkbox toggle-group popover command`.
- [x] `IngredientsSection`: строки «название + сырой вес + не учитывать + ×», «+ Ингредиент», Enter в поле веса → фокус на следующую строку / новую.
- [x] `WeighingSection`: переключатель «Без тары / С тарой»; для «с тарой» — `TarePicker` + «Вес с тарой» → «Без тары N г».
- [x] `TarePicker`: выбор из библиотеки, «+ Новая тара» прямо в выпадающем блоке (сохраняет в библиотеку и выбирает); при выборе во взвешивание записывается снимок `{id, name, grams}`.
- [x] Показ k: «k = 2,8» / «k блюда = 0,94».
- [x] Ошибки и предупреждения из `validation.ts`: вес с тарой ≤ тары, k вне диапазона (с подсказкой про тару), все ингредиенты исключены.
- [x] `updatedAt` обновляется при правках (для сортировки списка).
- [x] Строка списка готовок показывает готовый вес и k.

## Файлы
`src/screens/Cooking/**` (`IngredientsSection`, `WeighingSection`, `TarePicker`, стили), `src/components/ui/*` (новые shadcn-компоненты), `src/screens/CookingList/**` (строка), при необходимости `src/store/store.ts`.

## Definition of Done
- Пример 1 руками: гречка 200, «Кастрюля 850», вес с тарой 1410 → «Без тары 560 г · k = 2,8».
- Пример 2 руками: 7 ингредиентов, вода и соль «не учитывать», без тары 3160 → «k блюда = 0,94».
- Изменение веса тары в настройках не меняет уже введённое взвешивание.
- Вес с тарой 800 при таре 850 → ошибка текстом.
- 375 px без горизонтальной прокрутки; на десктопе две колонки (правая пока пустая или с заглушкой «Порции»).
- lint/test/build проходят.

## Способ проверки
- Сценарии из DoD на 375 px и на десктопе.
- Без тары ввести 1410 для гречки 200 → предупреждение «Необычный выход k = 7,05… выберите тару».
- Перезагрузка — все значения на месте, режим взвешивания и тара тоже.
- На телефоне (`pnpm dev --host`): цифровая клавиатура, запятая работает, iOS не зумит при фокусе.
