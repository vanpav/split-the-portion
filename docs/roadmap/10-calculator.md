# 10 — Калькулятор блюда

## Цель
Нажал блюдо — сразу калькулятор, как в лучших конвертерах величин (встроенный калькулятор iPhone в режиме конвертера, CONVERT UNITS, Unit Converter): крупные строки значений, активная подсвечена, своя клавиатура внизу, ответ пересчитывается на каждое нажатие (SPEC §3б).

## Задачи
- [x] Домен: `keypad.ts` (`applyKey`, `keypadKeyFromKeyboard`), `draft.ts` (`cookingDraft`), тесты.
- [x] Стор: `saveCooking(draft)` вместо `startCooking`; экран старта удалён.
- [x] `#/d/:id` — калькулятор; история блюда — `#/d/:id/history`; строка списка открывает калькулятор.
- [x] Клавиатура на телефоне, ввод с обычной клавиатуры на десктопе; калькулятор пересоздаётся при смене блюда.
- [x] Документы: SPEC §3б, UX, ARCHITECTURE.

## Проверено
375 px: макароны 130 → нажатия 3-1-2 → Ваня 168, Ксюша 144; «Сухой» → 1-5-0 заменяет 130; «С тёщей» → 115 / 99 / 99; до «Сохранить» записей не прибавилось, после — одна, с этими цифрами. 1280 px: суп, ввод 3160 с клавиатуры, состав у каждого. Переход макароны → суп не переносит цифры.

## Доработка: «Сегодня едят»
- [x] Общий состав людей на все блюда (`lineup`, v5), «+ Человек», имя в строке, × — убрать; доля нового — средняя.
- [x] Чипы пресетов заменяют состав; подсвечен совпадающий; «Сохранить как компанию».
- [x] Своя клавиатура прячется, пока вводится имя; тосты сверху, чтобы не закрывать клавиатуру.
Проверено на 375 px: макароны 130/312 + Тёща + Гость → 84/72/78/78, перезагрузка и суп — состав на месте; «Сохранить как компанию» → новый подсвеченный чип; «Ваня и Ксюша» → снова двое.

## Доработка: компактные пресеты и нижнее меню
- [x] Пресеты — выпадающий список «Ваня и Ксюша · 2 ▾» (или «Свой состав · 4») в одной строке с «+ Человек» и иконкой «Сохранить как компанию».
- [x] Нижнее меню: «Простые», «Составные», «Добавить» (выбор вида блюда), «Настройки»; вкладки над списком и шестерёнка в шапке убраны.
