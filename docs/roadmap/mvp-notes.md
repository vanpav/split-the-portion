## Замечено при разработке (проверить на телефоне)

- **Красная сверка при намеренном остатке.** Если часть блюда оставлена на завтра, «Не распределено N г» горит красным, хотя это не ошибка. Возможное решение: считать «В кастрюле» нормальным исходом и красить только перебор — или кнопка «Оставить на потом».
- **Новый этап без людей.** После перевзвешивания порции из состава по умолчанию не создаются, каждого человека добавляем «+ Человек». Проверить, удобно ли.
- **Прошлые этапы свёрнуты.** Чтобы скопировать для трекера порцию вчерашнего этапа, её нужно развернуть. Проверить, не мешает ли.
- **Пустое перевзвешивание.** «Перевзвесить остаток» активна только после ввода веса текущего этапа — иначе можно наплодить пустых этапов.
- **«остаток N г» в списке** появляется, только когда что-то взяли или перевзвесили; при пустом последнем взвешивании не показывается.
