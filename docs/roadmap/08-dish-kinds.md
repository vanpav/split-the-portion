# 08 — Простые и составные блюда

## Цель
Разделить интерфейс: простые блюда (один продукт — гречка, макароны, картофель) и составные (суп, плов) живут на отдельных вкладках и выглядят по-разному. Составное можно собрать на основе простого (SPEC §3). Расчётное ядро не меняется.

## Зависимости
07.

## Задачи
- [x] `Cooking.kind: 'simple' | 'composite'`, `CURRENT_VERSION = 3`, миграция v2 → v3 с тестом.
- [x] Стор: `createCooking(kind, base?)`, `addIngredientFrom(cookingId, { name, rawGrams })`.
- [x] Список: вкладки `Tabs` «Простые | Составные», вкладка в адресе (`?kind=composite`), своя кнопка создания и пустое состояние.
- [x] Экран простого блюда: секция «Продукт» (название + сырой вес), кнопка «Составное на основе».
- [x] Экран составного: «Из простого блюда» рядом с «+ Ингредиент».
- [x] Документы: SPEC §2–3, UX §2–6, ARCHITECTURE §3, §5.
