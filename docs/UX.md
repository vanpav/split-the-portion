# UX: экраны и потоки (MVP)

Статус: черновик на ревью · 2026-10-01. Термины — в [SPEC.md §2](SPEC.md#2-глоссарий).

## 1. Карта экранов

Два режима: **настройка** (блюдо, компании, тара — редко, с явным «Создать» / «Сохранить») и **калькулятор** (каждый день: нажал блюдо — ввёл две цифры — видишь, сколько класть каждому). Калькулятор устроен как конвертер величин (SPEC §3б).

```
┌──────────────────┐ «+ Простое блюдо»  ┌──────────────────┐
│ Блюда            │ ─────────────────▶ │ Редактор блюда   │ «Создать» ─┐
│ #/  [Простые|    │                    │ #/d/new, /edit   │            │
│      Составные]  │ тап по строке      └──────────────────┘            ▼
│  Макароны [Готовить] ───────────────────────────────────▶ ┌──────────────────┐
└────────┬─────────┘                                         │ Блюдо #/d/<id>   │
         │ «Готовить» → старт #/d/<id>/start → «Старт»    │ [Готовить]       │
         ▼                                                   │ Изменить · Удал. │
┌────────────────────┐ ◀──────────────────── «Готовить» ──── │ История готовок  │
│ Готовка #/c/<id>   │                                       └──────────────────┘
│  Сегодня: сухой,   │
│  вес после готовки │      История #/history: все готовки по дням → Готовка
│                    │      ⚙ → Настройки #/settings: Тара, Компании
│  Кто ест: люди     │
│  ▸ Подробнее       │
└────────────────────┘
```

**Нижнее меню (tab bar)** на экранах верхнего уровня — «Простые», «Составные», «Добавить» (по центру, залитая чёрная кнопка, сразу открывает форму блюда), «История» (`#/history`: все сохранённые готовки всех блюд, новые сверху, по дням — «Сегодня», «Вчера», «12 окт.»; у записи название блюда, время и сводка; тап открывает готовку), «Настройки». Активный пункт — иконка, обведённая контуром, и жирная подпись. На калькуляторе, в редакторе и в готовке его нет: низ занят клавиатурой или «Сохранить». С `lg` меню — вертикальная панель слева. Шапка: «← назад» на вложенных экранах, заголовок, действия экрана (история, правка).

## 2. Основные потоки

### П0. Настроить один раз
1. Настройки → «Компании» → «+ Компания» → в поле «+ Имя» сразу фокус: «Ваня», Enter, «Ксюша», Enter → полоса долей, как в калькуляторе: тянем границу или «− Ваня +» до 54 : 46. Название можно не писать — будет «Ваня и Ксюша». Вторая: «С тёщей» — Ваня, Ксюша, Тёща, доли 37 : 32 : 31.
2. «Добавить» в нижнем меню → форма блюда: «Макароны 130» (плашка вверху — «Простое»; добавили «Соль» с «не учитывать» — по-прежнему «Простое»; добавили «Фарш» — «Составное»), тара, кто ест → **«Создать»**. Пока не нажато «Создать», ничего не сохраняется; «Отмена» возвращает назад.

### П1. Сварить макароны (каждый день)
1. Блюда → нажимает «Макароны». Открывается калькулятор: «Сухой 130 г», «Ваня и Ксюша» выбраны, активна строка «Готовый».
2. Сегодня захотели побольше — тап по «Сухой», на клавиатуре 1-5-0 (первая цифра заменяет 130; рецепт не меняется).
3. Сварил, взвесил → тап «Готовый» (или ↓) → 3-6-0. Сразу видит «Ваня 194 г», «Ксюша 166 г» (делится 70 : 60, сколько бы воды ни взяли макароны). Ничего не записано, пока не нажато «Сохранить».
4. Приехала тёща → чип «С тёщей» → «Ваня 133 г», «Ксюша 114 г», «Тёща 114 г». Или в поле «+ Имя» внизу списка: «Тёща», Enter (и ещё сколько угодно людей); состав запоминается для всех блюд, «Сохранить состав как компанию» в списке компаний превращает его в пресет. Назад — тап по «Ваня и Ксюша».
5. Ване сегодня меньше → тап по «доля 70» под его именем → на клавиатуре 5-0 → доли и порции пересчитались. (В сохранённой готовке можно и «Своя порция в граммах»:) тап по «Ваня» → «Делит на всех» ⇄ «Своя порция в граммах» → 50 г сухого → Ване 120 г, Ксюше и тёще — остальное по долям.
6. ⧉ у своей строки → в буфере «Макароны (сырой вес) — 50 г».

### П2. Суп (составное)
1. «Составные» → «+ Составное блюдо» → «Суп», ингредиенты курица 600 … рис 80, вода 2000 «не учитывать» → «Создать».
2. «Готовить» → при необходимости правит сегодняшние веса → вес после готовки 3160 → «k блюда = 0,94».
3. У каждого человека — готовый вес и состав в сыром виде («Курица 75 г · Картофель 50 г …»). Своя порция — в готовом весе или «сырой: курица».
4. «Подробнее» → «Разделить на N» → 8 → «по 395 г» и состав одной порции.

### П3. Остаток на завтра
Чтобы что-то осталось, людям задают свои порции в граммах (порции по доле делят всё). Дальше «Подробнее» → «Перевзвесить остаток» → новое взвешивание (фокус в поле веса) → «k остатка». Прошлый этап сворачивается в строку «Этап 1 · Ваня, Ксюша».

### П3а. Составное на основе простого
1. На экране блюда «Макароны» → «Составное на основе» → редактор нового составного: первый ингредиент «Макароны 130 г», тара и компания как у макарон; фокус на следующем ингредиенте.
2. Или в редакторе составного → «Из простого блюда» → «Макароны» → ингредиент добавляется в конец (пустая последняя строка заменяется).

### П4. Новая тара прямо у плиты
В калькуляторе тап по таре под «Готовый» → в конце списка «+ Добавить тару» → диалог «Новая тара» с той же формой, что в настройках: «Название» и «Вес» (точно — в поле, примерно — ползунком под ним) → «Добавить тару» → диалог закрыт, тара выбрана и записана в библиотеку.
На экране сохранённой готовки так же: «изменить» → «С тарой» → в TarePicker «+ Новая тара» → та же форма прямо в списке.

## 3. Поведение элементов

- **Списки блюд** «Простые» и «Составные» — вкладки нижнего меню; выбранная — в адресе (`#/?kind=composite`). Тап по строке открывает калькулятор блюда.
- **Редактор блюда:** черновик живёт в форме, сохраняется только кнопкой «Создать» / «Сохранить» (неактивна, пока не хватает данных; под ней текст, чего не хватает). Простое: «Продукт» + «Обычный сухой вес». Составное: «Название», строки ингредиентов (название · обычный сырой вес · ×, «не учитывать»), «+ Ингредиент», «Из простого блюда». Общее: «В чём взвешиваете» (по умолчанию «Без тары»; или тара из библиотеки), «Кто ест» (компания или «Выберу при готовке»).
- **Экран старта** (`#/d/<id>/start`): «Сегодня» — сухой вес из рецепта, чипы «Кто ест», кнопка «Старт». До «Старт» в хранилище ничего не пишется; «← Блюдо» просто возвращает назад.
- **Экран готовки — карточка «Сегодня»:** сухой вес (или сырые веса ингредиентов) из рецепта, поле «Вес после готовки» и строка «в «Кастрюля 3 л» · 850 г — изменить»; переключатель «Без тары / С тарой» и выбор тары появляются только после «изменить». Под полем — «Без тары 312 г · k = 2,4».
- **«Кто ест»:** чипы компаний (`ToggleGroup`, выбранная залита основным цветом). Выбор компании заменяет людей текущего этапа. Строка человека: имя слева, крупно готовый вес справа, ⧉; под ней сухой вес или состав, «своя порция», если задана в граммах. Тап по строке раскрывает: имя, переключатель «Делит на всех ⇄ Своя порция в граммах», поле доли или поле граммов с единицами («сухой ⇄ готовый» кнопкой, у составного — `Select`), «Остаток», «Убрать» (тост «Удалено · Отменить»).
- **«Подробнее»** (свёрнуто): сверка, «В кастрюле», «Разделить на N», «Перевзвесить остаток».
- **Новая тара** — одна форма везде (настройки, диалог «Добавить тару» в калькуляторе, TarePicker на экране готовки): «Название», «Вес» — поле граммов и под ним ползунок от 10 до 3 000 г с шагом 10 г, оба показывают одно значение (тара тяжелее 3 кг вводится в поле, ползунок стоит в конце); кнопка «Добавить тару» неактивна, пока нет названия и веса больше 0. После добавления в настройках форма очищается для следующей тары.
- **Компании в настройках:** правятся на месте тем же интерфейсом, что «Кто ест» в калькуляторе (SPEC §3б): название, полоса долей (тянуть границы, «− Ваня 54 % +», «Поровну»; без «На завтра» и без «г | %» — блюда здесь нет, только проценты), под ней люди (имя · % · × удержанием, как в калькуляторе), внизу поле «+ Имя» (Enter — человек добавлен с долей, средней по остальным, поле готово для следующего). Новая компания открывается пустой, с фокусом в «+ Имя». Удаление компании — с тостом «Отменить».
- **Копирование:** тост «Скопировано» с первой строкой текста; без доступа к буферу — диалог с выделенным текстом.
- **Удаление** блюда и готовки — через `AlertDialog`; блюдо удаляется вместе с готовками. Перевзвешивание с порциями — тоже через `AlertDialog`.
- **Ошибки ввода** — под полем, красным, текстом.

- **Компоновка (после /impeccable adapt distill):** без карточек — секции с заголовками и отступами; главная кнопка экрана («Готовить», «Старт», «Создать / Сохранить») на телефоне прилипает к низу под большой палец, на десктопе стоит сразу после основного содержимого. На телефоне «назад» в шапке — только стрелка. На экране готовки «Сухой вес» и «Готовый вес» в одном ряду, под ними одна тихая строка «без тары · k = 2,4 · изменить»; у человека имя и сухой вес слева, готовый вес крупно справа.

### Настройки
Тара, «Убрать человека» (сколько держать ×: Сразу / 1 с / 1,5 с / 2 с), «Копия данных» («Скачать» / «Загрузить» JSON-файл; загрузка — после подтверждения, с «Отменить»), «Популярные блюда» (кнопка «Добавить популярные блюда»: около 30 простых и 20 составных рецептов с обычным весом, без тары; добавляются к своим блюдам в конец списка, блюда с таким же названием пропускаются; если в приложении уже есть блюда или готовки — сначала подтверждение; после добавления тост с «Отменить»; когда добавлять нечего, кнопка неактивна с подписью «Все популярные блюда уже добавлены»), компании. ## 5. Десктоп (≥ 1024 px, `lg`)

Экран готовки — две колонки: слева «Сегодня», справа «Кто ест» (sticky). Список блюд, блюдо и редактор — одна колонка шириной ≤ 720 px по центру; настройки — две колонки (тара, компании).

## 6. Тексты интерфейса (словарь)

| Ключ | Текст |
|---|---|
| Экран готовки | «Сегодня», «Кто ест», «Подробнее» |
| Виды блюд | Вкладки «Простые» / «Составные»; кнопки «+ Простое блюдо», «+ Составное блюдо», «Готовить», «Составное на основе», «Из простого блюда» |
| Редактор | «Создать» (новое блюдо) / «Сохранить» (правка), «Отмена»; «Обычный сухой вес»; «Как обычно»: «В чём взвешиваете», «Кто ест» |
| Человек | «Делит на всех» ⇄ «Своя порция в граммах»; «Доля»; «Убрать» |
| Сухой / сырой | Простое блюдо — «сухой вес», «г сухого»; составное — «сырой вес», «г сырого» |
| Популярные блюда | «Популярные блюда», «Добавить популярные блюда», «Добавить популярные блюда?», «Добавить», «Блюда добавлены», «Все популярные блюда уже добавлены» |
| Режим взвешивания | «Без тары» / «С тарой» |
| Тара | «Выберите тару», «+ Добавить тару» (в списке тары калькулятора), «Новая тара», «Вес пустой посуды — вычтем его сами.», «Название», «Вес», «Добавить тару», «К списку» |
| Поле | «Вес с тарой», «Вес без тары» |
| k | «k = 2,8» (один учитываемый ингредиент), «k блюда = 0,94» (составное), «k остатка = 2,58». Название продукта в подпись k не вставляем: склонять его («k гречки») автоматически нельзя |
| Необычный k | «Необычный выход: k = 7,05. Возможно, в вес попала посуда — выберите тару.» (взвешивали без тары) / «… Проверьте веса.» |
| Все исключены | «Нечего записывать: все ингредиенты исключены» |
| Сверка ok | «Распределено 200 из 200 г сырого» |
| Перебор | «Перебор 10 г» |
| Недобор | «Не распределено 20 г» |
| Незаконченный ввод | «Осталось распределить 120 г» |
| Остаток | «В кастрюле: 56 г готового = 20 г сырого» |
| Ошибка тары | «Вес с тарой меньше веса тары — проверьте тару» |

Слова «нетто» и «брутто» не используются.
