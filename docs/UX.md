# UX: экраны и потоки (MVP)

Статус: черновик на ревью · 2026-10-01. Термины — в [SPEC.md §2](SPEC.md#2-глоссарий).

## 1. Карта экранов

Два режима: **калькулятор** (каждый день: открыл — блюдо уже выбрано или в один тап на полке, ввёл готовый вес — видишь, сколько класть каждому) и **настройка** (блюдо, компании, тара — редко, с явным «Создать» / «Сохранить»). Калькулятор устроен как конвертер величин (SPEC §3б). С этапа 15 нет нижнего меню, готовок и истории.

```
┌──────────────────────────────────────┐  «⋯» → Изменить «Гречка» → Редактор #/d/<id>/edit
│ 🔍 ☰ (Гречка) Макароны Рис …       ⋯ │  «⋯» → Добавить блюдо     → Редактор #/d/new
├──────────────────────────────────────┤  «⋯» → Настройки          → #/settings
│ Калькулятор #/d/<id>  (главный, #/ → │  ☰  → Все блюда #/dishes («⋯»: Добавить блюдо, Настройки)
│ последнее блюдо)                     │  🔍 → поиск: свои блюда, популярные с весом
│ Сухой 70 г | Готовый 186 г           │
│ Кто ест · полоса долей · люди        │  Без блюд #/ — «Пока нет блюд»: «Блюдо», «Популярные блюда»
│ клавиатура                           │  Аккаунт #/account · ссылка-приглашение → Вступить #/join/<код>
└──────────────────────────────────────┘
```

**Шапки.** На калькуляторе — полка блюд (поиск и «Все блюда» в начале вне прокрутки, чипы по последнему использованию, «⋯» справа). На остальных экранах — «← назад», заголовок и «⋯» с действиями экрана и «Настройками» (везде одно меню). Точка «нужно внимание» (синхронизация) — на «⋯» и на пункте «Настройки».

## 2. Основные потоки

### П0. Настроить один раз
1. Настройки → «Компании» → «+ Компания» → в поле «+ Имя» сразу фокус: «Ваня», Enter, «Ксюша», Enter → полоса долей, как в калькуляторе: тянем границу или «− Ваня +» до 54 : 46. Название можно не писать — будет «Ваня и Ксюша». Вторая: «С тёщей» — Ваня, Ксюша, Тёща, доли 37 : 32 : 31.
2. «⋯» → «Добавить блюдо» → форма «Добавить блюдо»: «Макароны 130» (переключатель вверху — «Простое»; добавили «Соль» с «не учитывать» — по-прежнему «Простое»; добавили «Фарш» — «Составное»; «Составное» можно выбрать и сразу — появится строка для второго продукта), тара → **«Создать»**. Пока не нажато «Создать», ничего не сохраняется; «Отмена» возвращает назад. Или 🔍 → «макар» → «Макароны · 250 г» из популярных — блюдо добавлено и открыто.

### П1. Сварить макароны (каждый день)
1. Открывает приложение — сразу калькулятор блюда, которым пользовались последним; другое — тап по чипу на полке или 🔍. «Сухой 130 г» (как в прошлый раз), «Ваня и Ксюша» с прошлыми долями, активна плитка «Готовый».
2. Сегодня захотели побольше — тап по «Сухой», на клавиатуре 1-5-0 (первая цифра заменяет 130). Блюдо запоминает 150: в следующий раз будет 150.
3. Сварил, взвесил → тап «Готовый» (или ↓) → 3-6-0. Сразу видит «Ваня 194 г», «Ксюша 166 г» (делится 70 : 60, сколько бы воды ни взяли макароны). Сохранять нечего: готовый вес тоже записан в блюдо с временем, и Ксюша на своём телефоне видит «Готовый 360 · 19:40» и свою порцию.
4. Приехала тёща → «Ваня и Ксюша ▾» → «С тёщей» → «Ваня 133 г», «Ксюша 114 г», «Тёща 114 г». Или в поле «+ Имя» внизу списка: «Тёща», Enter. Состав и доли запоминаются у этого блюда (у других блюд — свои), «Сохранить состав как компанию» в списке компаний превращает его в пресет. Новая компания прямо отсюда: в конце списка «Добавить компанию» → диалог «Новая компания» → компания выбрана.
5. Ване сегодня меньше → тап по его числу → на клавиатуре 1-2-0 → Ване 120 г, Ксюше остальное по долям. Уходит из поля — его часть блюда запоминается как доля: в следующий раз сразу так.
6. ⧉ у своей строки → в буфере «Макароны (сырой вес) — 50 г».

### П2. Суп (составное)
1. «Составные» → «+ Составное блюдо» → «Суп», ингредиенты курица 600 … рис 80, вода 2000 «не учитывать» → «Создать».
2. Тап «Суп» на полке → продукты свёрнуты в «Сырой 1 080 г · не учит.: Вода 2 000 г» → вес после готовки 3160 → «k блюда = 1,03». Поправить сегодняшний вес продукта — «Продукты ⌄».
3. У каждого человека — готовый вес и состав в сыром виде («Курица 323 г · Картофель 215 г · Рис 43 г»). Своя порция — в граммах или процентах.

### П3. Остаток на завтра
Потянуть правый край полосы долей влево — «На завтра 20 %»: делящие получают меньше, под списком «В кастрюле останется — на завтра: 72 г» и сухой вес. Завтра — открыть блюдо, ввести этот сухой вес и новый готовый вес остатка. Отдельного перевзвешивания и этапов в приложении нет (этап 15).

### П3а. Составное на основе простого
1. «⋯» → «Изменить «Макароны»» → «Составное на основе» → редактор нового составного: первый ингредиент «Макароны 130 г», тара как у макарон; фокус на следующем ингредиенте.
2. Или в редакторе составного → «Из простого блюда» → «Макароны» → ингредиент добавляется в конец (пустая последняя строка заменяется).

### П4. Новая тара прямо у плиты
Под плитками тап по таре → в конце списка «Добавить тару» → диалог «Новая тара» с той же формой, что в настройках: «Название» и «Вес» (точно — в поле, примерно — ползунком под ним) → «Добавить тару» → диалог закрыт, тара выбрана, записана в библиотеку и запомнена у блюда.

### П5. Установить на iPhone (этап 11)
1. Safari → адрес приложения → «Поделиться» → «На экран „Домой“» → «Порции».
2. Иконка открывает приложение без строки Safari, сразу на последнем блюде. Без сети всё работает.
3. Данные из Safari сюда не переезжают: у приложения на экране «Домой» своё хранилище. Перенести — войти в аккаунт (П6) или «Копия данных»: «Скачать» в Safari, «Загрузить» в приложении.
4. После обновления на сервере при следующем открытии — тост «Есть новая версия · Обновить». Пока не нажато, работает старая версия.

### П6. Аккаунт и общий учёт с Ксюшей (этапы 12–14)
1. **Ваня:** Настройки → «Аккаунт» → «Войти» → «Создать аккаунт»: почта, пароль (iPhone предлагает сохранить его в Связке ключей) → его блюда теперь в группе «Личная». «Добавить вход по Face ID».
2. Настройки → «Группа» → «Пригласить» → код `K7MR-Q2XD` крупно и «Поделиться» → ссылка в Telegram Ксюше.
3. **Ксюша:** ссылка открывается в Safari → «Создать аккаунт» → «Вступить в группу „Личная“? Пригласил: vanya» → «Вступить» → «Открывать эту группу при запуске?» → «Да».
   Если приложение у неё уже на экране «Домой»: Safari показывает код, она открывает приложение → Настройки → «Группа» → «Вступить по коду».
4. Теперь у обоих одни блюда, тара и компании; готовый вес, который ввела Ксюша, через минуту (или при открытии приложения) виден у Вани в этом блюде: «Готовый 360 · 19:40».
5. Без сети всё работает; в «Аккаунте» — «Нет сети — изменения сохранены на устройстве». Сеть появилась — «Синхронизировано · 19:42».

## 3. Поведение элементов

- **Полка блюд** (шапка калькулятора): 🔍 и ☰ «Все блюда» — круглые кнопки в начале, вне прокрутки, с подсказками при наведении («Найти блюдо ⌘K /», «Все блюда»). Дальше чипы (36 px на вид, 44 px для пальца) по последнему использованию; текущий обведён, тап по другому открывает его калькулятор. Пока полка открыта, порядок не меняется; новое блюдо встаёт в конец. «⋯» справа.
- **Поиск** (`CommandDialog`, вверху экрана — снизу клавиатура телефона): поле 16 px, «Ваши блюда» (справа вес или состав), «Популярные — добавить» (каталог «Популярных блюд», которых ещё нет, с весом). Тап по популярному — блюдо создано и открыто, тост «Блюдо добавлено · Булгур · 150 г · Отменить». Пусто — «Ничего не нашлось».
- **«⋯»** (`DropdownMenu`, пункты 44 px) — во всех шапках: действия экрана, разделитель, «Настройки». Калькулятор: «Изменить «Гречка»», «Добавить блюдо». Все блюда: «Добавить блюдо».
- **Все блюда** (`#/dishes`) — один список, последнее использованное сверху; строка: название и вес («80 г сухого») или состав; тап открывает калькулятор.
- **Редактор блюда:** черновик живёт в форме, сохраняется только кнопкой «Создать» / «Сохранить» (неактивна, пока не хватает данных; под ней текст, чего не хватает). Заголовок — «Добавить блюдо» / «Изменить блюдо». Вверху переключатель «Простое | Составное» (`ToggleGroup`, SPEC §3). Строки ингредиентов (название · сырой вес · ×, «не учитывать»), «+ Ингредиент», «Из простого блюда», «Название», «В чём взвешиваете» (по умолчанию «Без тары»). У существующего блюда внизу — «Составное на основе» (у простого) и «Удалить блюдо» (`AlertDialog`).
- **Плитки калькулятора:** «Сухой» (у составного свёрнутого — «Сырой ⌄» с суммой и пометкой «не учит.: …») и «Готовый» в ряд; подпись «Готовый · 19:40», если подставлен сегодняшний расчёт. Под плитками — тара, «без тары · k», у составного — «Продукты ⌄» / «Свернуть ⌃».
- **Компания в калькуляторе** (`Select` над полосой долей): выбор подставляет людей и доли компании в состав блюда; выбранная компания так и остаётся в поле, когда двигают ползунок или добавляют людей — компания и её название от этого не меняются. Состав и доли запоминаются у каждого блюда отдельно. Последний пункт — «Добавить компанию»: диалог «Новая компания» открывается, когда список закрылся, фокус в «+ Имя»; форма та же, что в настройках (`CompanyForm`).
- **Новая тара** — одна форма везде (настройки, диалог «Добавить тару» в калькуляторе): «Название», «Вес» — поле граммов и под ним ползунок от 10 до 3 000 г с шагом 10 г, оба показывают одно значение (тара тяжелее 3 кг вводится в поле, ползунок стоит в конце); кнопка «Добавить тару» неактивна, пока нет названия и веса больше 0. После добавления в настройках форма очищается для следующей тары.
- **Компании в настройках:** правятся на месте тем же интерфейсом, что «Кто ест» в калькуляторе (SPEC §3б): название, полоса долей (тянуть границы, «− Ваня 54 % +», «Поровну»; без «На завтра» и без «г | %» — блюда здесь нет, только проценты), под ней люди (имя · % · × удержанием, как в калькуляторе), внизу поле «+ Имя» (Enter — человек добавлен с долей, средней по остальным, поле готово для следующего). Новая компания открывается пустой, с фокусом в «+ Имя». Удаление компании — с тостом «Отменить».
- **Копирование:** тост «Скопировано» с первой строкой текста; без доступа к буферу — диалог с выделенным текстом.
- **Удаление** блюда — через `AlertDialog` в редакторе; вместе с ним уходит его состав «Кто ест».
- **Ошибки ввода** — под полем, красным, текстом.

- **Компоновка (после /impeccable adapt distill):** без карточек — секции с заголовками и отступами; главная кнопка экрана («Создать / Сохранить») на телефоне прилипает к низу под большой палец, на десктопе стоит сразу после основного содержимого. На телефоне «назад» в шапке — только стрелка. В калькуляторе «Сухой» и «Готовый» в одном ряду, под ними одна тихая строка «Без тары · k = 2,4»; у человека имя и сухой вес слева, готовый вес крупно справа.

- **Цвета едоков:** у каждого человека из сегодняшнего состава свой цвет крышки (небо, подсолнух, мята, сирень, абрикос; с шестого — по кругу). Им окрашены его сегмент в полосе долей (48 px, имя и под ним граммы; между полосой и «− Ваня +» 12 px) и метка у имени. Своя порция в граммах — та же крышка бледнее, с пунктирной рамкой. Выбранный для «±1 %» — обведён, цвет сохраняется. Различие дублируется именем, не только цветом.
- **Курсор калькулятора** в поле, куда печатает клавиатура, моргает и при каждом появлении меняет цвет на крышку следующего едока. Без людей моргает основным цветом; при «уменьшить движение» — ровный курсор основного цвета.
- **Активное поле** калькулятора — белая «коробка» с рамкой на матовом фоне. Служебные клавиши (⌫, C, ↓) — без рамок, тише цифр.

## 4. Вайрфреймы — телефон (375 px)

### Калькулятор (главный экран)
```
┌─────────────────────────────────────┐
│ (🔍)(☰) (Гречка) Макароны Рис …   ⋯ │  ← полка: чипы листаются
├─────────────────────────────────────┤
│ ┌ Сухой ──────┐ ┌ Готовый · 19:40─┐ │
│ │ 70 г        │ │ 186| г          │ │  ← активная плитка
│ └─────────────┘ └─────────────────┘ │
│ Без тары ⌄  k = 2,66                │
│ [👥 Ваня и Ксюша · 2            ⌄ ] │
│ [▓ Ваня  ▓▓▓◉░░ Ксюша ░░]           │  ← полоса, 48 px
│ 100 г          86 г                 │
│ [−] Ваня 100 г [+]   Поровну  [г|%] │
│ ■ Ваня                  100 г [г] ⧉ │
│   53,8 % · 38 г сухого            × │
│ ■ Ксюша                  86 г [г] ⧉ │
│ + Имя                               │
├─────────────────────────────────────┤
│ [ 7 ] [ 8 ] [ 9 ] [ ⌫ ]             │
│ [ 4 ] [ 5 ] [ 6 ] [ C ]             │
│ [ 1 ] [ 2 ] [ 3 ] [   ]             │
│ [ , ] [    0    ] [ ↓ ]             │
└─────────────────────────────────────┘
```
Составное свёрнуто: `┌ Сырой ⌄ ─────┐ ┌ Готовый ┐` · «1 080 г» · «не учит.: Вода 2 000 г»; под плитками справа «Продукты ⌄».


### Настройки
Разбиты на подразделы, у каждого свой адрес `#/settings/<подраздел>` (назад/вперёд и перезагрузка возвращают туда же):

| Подраздел | Адрес | Что внутри | Подпись в меню |
|---|---|---|---|
| «Тара» | `tares` | справочник тары | «Вес пустой посуды» |
| «Компании» | `companies` | компании; под ними «Убрать человека» (сколько держать ×: Сразу / 1 с / 1,5 с / 2 с) — тоже про людей | «Кто ест вместе» |
| «Популярные блюда» | `presets` | кнопка «Добавить популярные блюда»: около 30 простых и 20 составных рецептов с обычным весом, без тары; добавляются к своим блюдам в конец списка, блюда с таким же названием пропускаются; если в приложении уже есть блюда — сначала подтверждение; после добавления тост с «Отменить»; когда добавлять нечего, кнопка неактивна с подписью «Все популярные блюда уже добавлены» | «Готовые рецепты для начала» |
| «Копия данных» | `data` | «Скачать» / «Загрузить» JSON-файл; загрузка — после подтверждения, с «Отменить». Вошли — подтверждение говорит, что данные группы заменятся у всех её участников. Без аккаунта — подпись: «У приложения на экране „Домой“ iPhone своё хранилище… Проще всего войти в аккаунт и там, и там…» | «Скачать или загрузить файл» |
| «Оформление» | `appearance` | «Тема»: Как в системе / Светлая / Тёмная (по умолчанию — как в системе). Выбор запоминается в этом браузере и не попадает в копию данных | «Светлая или тёмная тема» |
| «Аккаунт» (этап 12, первым в меню) | `account` | Не вошли — «Данные только на этом устройстве. Войдите, чтобы данные были на всех устройствах и в общей группе.» и «Войти» → `#/account`. Вошли — почта, статус синхронизации (этап 13), «Добавить вход по Face ID» / «Face ID добавлен», «Выйти» (только с сетью; данные групп уходят с устройства, на сервере остаются) | Не вошли — «Данные только на этом устройстве»; вошли — почта |
| «Группа» (этап 14, только после входа) | `group` | Выбор группы (если их несколько; чужая — «Личная · vanya») и ★ «Открывается при запуске» / «Открывать при запуске»; название (правит владелец, на месте); участники (× удержанием — убрать, только владелец); «Пригласить»; «Вступить по коду»; «Выйти из группы» (только в чужой группе) | Название открытой группы |

**Телефон (< 768 px):** `#/settings` — список подразделов (иконка, название, подпись, «›»). Тап открывает подраздел отдельным экраном: в шапке «←» обратно к списку и название подраздела. Нижнее меню остаётся на всех экранах настроек, «Настройки» в нём активны.

**Планшет и десктоп (≥ 768 px, `md`):** слева меню подразделов, справа выбранный подраздел, «←» в шапке нет. На `#/settings` справа открыт первый подраздел («Аккаунт», с этапа 12; до него — «Тара») и он же подсвечен в меню.

### Вход (`#/account`, этап 12)
```
│ ←  Аккаунт                          │
│ [ Войти | Создать аккаунт ]         │
│ Почта   [ vanya@example.com       ] │
│ Пароль  [ ••••••••                ] │
│ [            Войти              ]   │
│ [  ◉ Войти с Face ID            ]   │
│ Забыли пароль?                      │
```
- Поля: `autocomplete="email"`, `"current-password"` / `"new-password"` — iPhone предлагает и сохраняет пароль. В поле почты iPhone сам предлагает Face ID, если он уже добавлен.
- Без сети: после нажатия «Войти» — «Нет сети — войти можно, когда она появится».
- «Забыли пароль?» (пока нет писем): нужна почта в поле; под полями — «Ссылку для нового пароля пришлёт владелец приложения — напишите ему». По ссылке — экран «Новый пароль» (`#/account/reset`) → «Сохранить пароль» → тост «Пароль изменён — войдите с ним».
- Ошибки — под полем пароля, свои, по-русски (подсказки браузера выключены): «Пароль — не короче 8 символов», «Неверная почта или пароль», «Такая почта уже зарегистрирована», «Нет сети — войти можно, когда она появится», «Face ID не сработал — войдите паролем».
- После входа — в Настройки → «Аккаунт». Данные, которые были на устройстве без аккаунта, переезжают в группу «Личная»: молча, если в ней пусто; иначе `AlertDialog` «Перенести данные этого устройства?» → «Перенести» / «Не переносить». Копия данных устройства в любом случае остаётся в браузере.

### Аккаунт и группа (Настройки, этапы 12–14)
```
Аккаунт                               Группа
│ vanya@example.com                │  │ [ Личная ★              ⌄ ]   │
│ ✓ Синхронизировано · 19:42       │  │ Название [ Личная         ]   │
│ ◉ Face ID добавлен               │  │ Участники                     │
│ [ Выйти ]                        │  │ vanya · владелец              │
                                      │ ksusha                     ×  │
                                      │ [ + Пригласить ]              │
                                      │ Вступить по коду              │
                                      │ Выйти из группы               │
```
- «Пригласить» раскрывает на месте: код крупно (`K7MR-Q2XD`, моноширинные цифры), ссылка, «Копировать» и «Поделиться», «Действует до 13 окт.», у владельца — «Отозвать».
- Звёздочка у группы по умолчанию; у другой группы в списке — «Открывать при запуске».
- Переключение группы открывает список блюд этой группы.
- Статус синхронизации — одной строкой под почтой. Если нужно действие («Войдите снова…» — с кнопкой «Войти снова», «Обновите приложение…», «Нет доступа к группе»), на пункте «Настройки» в нижнем меню — точка цвета `--warning`. «Нет сети…» — обычный режим, без точки.
- «Выйти» из аккаунта: если не всё отправлено — «Не все изменения отправлены. Выйти всё равно?».

### Вступить по ссылке (`#/join/:code`, этап 14)

- Нижний блок с кодом — только в браузере, в установленном приложении его нет.
- Код устарел или отозван — «Код не найден или устарел. Попросите новый».

## 5. Десктоп (≥ 1024 px, `lg`)

Калькулятор — одна колонка ≤ 28rem по центру, своей клавиатуры нет: цифры с обычной, Enter или ↓ — следующее поле, ⌘K — поиск. Список блюд и редактор — одна колонка шириной ≤ 720 px по центру; настройки — меню подразделов слева и выбранный подраздел справа (уже с `md`, см. «Настройки» выше).
