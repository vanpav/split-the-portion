# UX: экраны и потоки (MVP)

Статус: черновик на ревью · 2026-10-01. Термины — в [SPEC.md §2](SPEC.md#2-глоссарий).

## 1. Карта экранов

Два режима: **настройка** (блюдо, компании, тара — редко, с явным «Создать» / «Сохранить») и **калькулятор** (каждый день: нажал блюдо — ввёл две цифры — видишь, сколько класть каждому). Калькулятор устроен как конвертер величин (SPEC §3б).

```
┌──────────────────┐ «+ Простое блюдо»  ┌──────────────────┐
│ Блюда            │ ─────────────────▶ │ Редактор блюда   │ «Создать» ─┐
│ #/  [Простые|    │                    │ #/d/new, /edit   │            │
│      Составные]  │ тап по строке      └──────────────────┘            ▼
│  Макароны [Готовить] ───────────────────────────────────▶ ┌──────────────────┐
└────────┬─────────┘                                         │ Блюдо #/d/<id>   │
         │ «Готовить» → старт #/d/<id>/start → «Старт»    │ [Готовить]       │
         ▼                                                   │ Изменить · Удал. │
┌────────────────────┐ ◀──────────────────── «Готовить» ──── │ История готовок  │
│ Готовка #/c/<id>   │                                       └──────────────────┘
│  Сегодня: сухой,   │
│  вес после готовки │      История #/history: все готовки по дням → Готовка
│                    │      ⚙ → Настройки #/settings: Аккаунт, Группа, Тара, Компании, Популярные блюда, Копия данных, Оформление
│                    │      Аккаунт → Вход #/account · ссылка-приглашение → Вступить #/join/<код>
│  Кто ест: люди     │
│  ▸ Подробнее       │
└────────────────────┘
```

**Нижнее меню (tab bar)** на экранах верхнего уровня — «Простые», «Составные», «Добавить» (по центру, кнопка, залитая основным цветом, сразу открывает форму блюда), «История» (`#/history`: все сохранённые готовки всех блюд, новые сверху, по дням — «Сегодня», «Вчера», «12 окт.»; у записи название блюда, время и сводка; тап открывает готовку), «Настройки». Активный пункт — иконка, обведённая контуром, и жирная подпись. На калькуляторе, в редакторе и в готовке его нет: низ занят клавиатурой или «Сохранить». С `lg` меню — вертикальная панель слева. Шапка: «← назад» на вложенных экранах, заголовок, действия экрана (история, правка).

## 2. Основные потоки

### П0. Настроить один раз
1. Настройки → «Компании» → «+ Компания» → в поле «+ Имя» сразу фокус: «Ваня», Enter, «Ксюша», Enter → полоса долей, как в калькуляторе: тянем границу или «− Ваня +» до 54 : 46. Название можно не писать — будет «Ваня и Ксюша». Вторая: «С тёщей» — Ваня, Ксюша, Тёща, доли 37 : 32 : 31.
2. «Добавить» в нижнем меню → форма блюда: «Макароны 130» (плашка вверху — «Простое»; добавили «Соль» с «не учитывать» — по-прежнему «Простое»; добавили «Фарш» — «Составное»), тара, кто ест → **«Создать»**. Пока не нажато «Создать», ничего не сохраняется; «Отмена» возвращает назад.

### П1. Сварить макароны (каждый день)
1. Блюда → нажимает «Макароны». Открывается калькулятор: «Сухой 130 г», «Ваня и Ксюша» выбраны, активна строка «Готовый».
2. Сегодня захотели побольше — тап по «Сухой», на клавиатуре 1-5-0 (первая цифра заменяет 130; рецепт не меняется).
3. Сварил, взвесил → тап «Готовый» (или ↓) → 3-6-0. Сразу видит «Ваня 194 г», «Ксюша 166 г» (делится 70 : 60, сколько бы воды ни взяли макароны). Ничего не записано, пока не нажато «Сохранить».
4. Приехала тёща → чип «С тёщей» → «Ваня 133 г», «Ксюша 114 г», «Тёща 114 г». Или в поле «+ Имя» внизу списка: «Тёща», Enter (и ещё сколько угодно людей); состав и доли запоминаются у этого блюда (у других блюд — свои), «Сохранить состав как компанию» в списке компаний превращает его в пресет. Назад — тап по «Ваня и Ксюша». Новая компания прямо отсюда: в конце списка «Добавить компанию» → диалог «Новая компания» с формой из настроек → «Добавить компанию» → диалог закрыт, компания выбрана.
5. Ване сегодня меньше → тап по «доля 70» под его именем → на клавиатуре 5-0 → доли и порции пересчитались. (В сохранённой готовке можно и «Своя порция в граммах»:) тап по «Ваня» → «Делит на всех» ⇄ «Своя порция в граммах» → 50 г сухого → Ване 120 г, Ксюше и тёще — остальное по долям.
6. ⧉ у своей строки → в буфере «Макароны (сырой вес) — 50 г».

### П2. Суп (составное)
1. «Составные» → «+ Составное блюдо» → «Суп», ингредиенты курица 600 … рис 80, вода 2000 «не учитывать» → «Создать».
2. «Готовить» → при необходимости правит сегодняшние веса → вес после готовки 3160 → «k блюда = 0,94».
3. У каждого человека — готовый вес и состав в сыром виде («Курица 75 г · Картофель 50 г …»). Своя порция — в готовом весе или «сырой: курица».
4. «Подробнее» → «Разделить на N» → 8 → «по 395 г» и состав одной порции.

### П3. Остаток на завтра
Чтобы что-то осталось, людям задают свои порции в граммах (порции по доле делят всё). Дальше «Подробнее» → «Перевзвесить остаток» → новое взвешивание (фокус в поле веса) → «k остатка». Прошлый этап сворачивается в строку «Этап 1 · Ваня, Ксюша».

### П3а. Составное на основе простого
1. На экране блюда «Макароны» → «Составное на основе» → редактор нового составного: первый ингредиент «Макароны 130 г», тара и компания как у макарон; фокус на следующем ингредиенте.
2. Или в редакторе составного → «Из простого блюда» → «Макароны» → ингредиент добавляется в конец (пустая последняя строка заменяется).

### П4. Новая тара прямо у плиты
В калькуляторе тап по таре под «Готовый» → в конце списка «+ Добавить тару» → диалог «Новая тара» с той же формой, что в настройках: «Название» и «Вес» (точно — в поле, примерно — ползунком под ним) → «Добавить тару» → диалог закрыт, тара выбрана и записана в библиотеку.
На экране сохранённой готовки так же: «изменить» → «С тарой» → в TarePicker «+ Новая тара» → та же форма прямо в списке.

### П5. Установить на iPhone (этап 11)
1. Safari → адрес приложения → «Поделиться» → «На экран „Домой“» → «Порции».
2. Иконка открывает приложение без строки Safari. Без сети всё работает.
3. Данные из Safari сюда не переезжают: у приложения на экране «Домой» своё хранилище. Перенести — войти в аккаунт (П6) или «Копия данных»: «Скачать» в Safari, «Загрузить» в приложении.
4. После обновления на сервере при следующем открытии — тост «Есть новая версия · Обновить». Пока не нажато, работает старая версия.

### П6. Аккаунт и общий учёт с Ксюшей (этапы 12–14)
1. **Ваня:** Настройки → «Аккаунт» → «Войти» → «Создать аккаунт»: почта, пароль (iPhone предлагает сохранить его в Связке ключей) → его блюда и история теперь в группе «Личная». «Добавить вход по Face ID».
2. Настройки → «Группа» → «Пригласить» → код `K7MR-Q2XD` крупно и «Поделиться» → ссылка в Telegram Ксюше.
3. **Ксюша:** ссылка открывается в Safari → «Создать аккаунт» → «Вступить в группу „Личная“? Пригласил: vanya» → «Вступить» → «Открывать эту группу при запуске?» → «Да».
   Если приложение у неё уже на экране «Домой»: Safari показывает код, она открывает приложение → Настройки → «Группа» → «Вступить по коду».
4. Теперь у обоих одни блюда, тара и компании; готовка, сохранённая Ксюшей, через минуту (или при открытии приложения) видна у Вани в «Истории».
5. Без сети всё работает; в «Аккаунте» — «Нет сети — изменения сохранены на устройстве». Сеть появилась — «Синхронизировано · 19:42».

## 3. Поведение элементов

- **Списки блюд** «Простые» и «Составные» — вкладки нижнего меню; выбранная — в адресе (`#/?kind=composite`). Тап по строке открывает калькулятор блюда.
- **Редактор блюда:** черновик живёт в форме, сохраняется только кнопкой «Создать» / «Сохранить» (неактивна, пока не хватает данных; под ней текст, чего не хватает). Простое: «Продукт» + «Обычный сухой вес». Составное: «Название», строки ингредиентов (название · обычный сырой вес · ×, «не учитывать»), «+ Ингредиент», «Из простого блюда». Общее: «В чём взвешиваете» (по умолчанию «Без тары»; или тара из библиотеки), «Кто ест» (компания или «Выберу при готовке»).
- **Экран старта** (`#/d/<id>/start`): «Сегодня» — сухой вес из рецепта, чипы «Кто ест», кнопка «Старт». До «Старт» в хранилище ничего не пишется; «← Блюдо» просто возвращает назад.
- **Экран готовки — карточка «Сегодня»:** сухой вес (или сырые веса ингредиентов) из рецепта, поле «Вес после готовки» и строка «в «Кастрюля 3 л» · 850 г — изменить»; переключатель «Без тары / С тарой» и выбор тары появляются только после «изменить». Под полем — «Без тары 312 г · k = 2,4».
- **«Кто ест»:** чипы компаний (`ToggleGroup`, выбранная залита основным цветом). Выбор компании заменяет людей текущего этапа. Строка человека: имя слева, крупно готовый вес справа, ⧉; под ней сухой вес или состав, «своя порция», если задана в граммах. Тап по строке раскрывает: имя, переключатель «Делит на всех ⇄ Своя порция в граммах», поле доли или поле граммов с единицами («сухой ⇄ готовый» кнопкой, у составного — `Select`), «Остаток», «Убрать» (тост «Удалено · Отменить»).
- **Компания в калькуляторе** (`Select` над полосой долей): выбор подставляет людей и доли компании в состав блюда; выбранная компания так и остаётся в поле, когда двигают ползунок или добавляют людей — компания и её название от этого не меняются. Состав и доли запоминаются у каждого блюда отдельно. Последний пункт — «Добавить компанию»: диалог «Новая компания» открывается, когда список закрылся, фокус в «+ Имя»; форма та же, что в настройках (`CompanyForm`).
- **«Подробнее»** (свёрнуто): сверка, «В кастрюле», «Разделить на N», «Перевзвесить остаток».
- **Новая тара** — одна форма везде (настройки, диалог «Добавить тару» в калькуляторе, TarePicker на экране готовки): «Название», «Вес» — поле граммов и под ним ползунок от 10 до 3 000 г с шагом 10 г, оба показывают одно значение (тара тяжелее 3 кг вводится в поле, ползунок стоит в конце); кнопка «Добавить тару» неактивна, пока нет названия и веса больше 0. После добавления в настройках форма очищается для следующей тары.
- **Компании в настройках:** правятся на месте тем же интерфейсом, что «Кто ест» в калькуляторе (SPEC §3б): название, полоса долей (тянуть границы, «− Ваня 54 % +», «Поровну»; без «На завтра» и без «г | %» — блюда здесь нет, только проценты), под ней люди (имя · % · × удержанием, как в калькуляторе), внизу поле «+ Имя» (Enter — человек добавлен с долей, средней по остальным, поле готово для следующего). Новая компания открывается пустой, с фокусом в «+ Имя». Удаление компании — с тостом «Отменить».
- **Копирование:** тост «Скопировано» с первой строкой текста; без доступа к буферу — диалог с выделенным текстом.
- **Удаление** блюда и готовки — через `AlertDialog`; блюдо удаляется вместе с готовками. Перевзвешивание с порциями — тоже через `AlertDialog`.
- **Ошибки ввода** — под полем, красным, текстом.

- **Компоновка (после /impeccable adapt distill):** без карточек — секции с заголовками и отступами; главная кнопка экрана («Готовить», «Старт», «Создать / Сохранить») на телефоне прилипает к низу под большой палец, на десктопе стоит сразу после основного содержимого. На телефоне «назад» в шапке — только стрелка. На экране готовки «Сухой вес» и «Готовый вес» в одном ряду, под ними одна тихая строка «без тары · k = 2,4 · изменить»; у человека имя и сухой вес слева, готовый вес крупно справа.

- **Цвета едоков:** у каждого человека из сегодняшнего состава свой цвет крышки (небо, подсолнух, мята, сирень, абрикос; с шестого — по кругу). Им окрашены его сегмент в полосе долей и метка у имени. Своя порция в граммах — та же крышка бледнее, с пунктирной рамкой. Выбранный для «±1 %» — обведён, цвет сохраняется. Различие дублируется именем, не только цветом.
- **Курсор калькулятора** в поле, куда печатает клавиатура, моргает и при каждом появлении меняет цвет на крышку следующего едока. Без людей моргает основным цветом; при «уменьшить движение» — ровный курсор основного цвета.
- **Активное поле** калькулятора — белая «коробка» с рамкой на матовом фоне. Служебные клавиши (⌫, C, ↓) — без рамок, тише цифр.

### Настройки
Разбиты на подразделы, у каждого свой адрес `#/settings/<подраздел>` (назад/вперёд и перезагрузка возвращают туда же):

| Подраздел | Адрес | Что внутри | Подпись в меню |
|---|---|---|---|
| «Тара» | `tares` | справочник тары | «Вес пустой посуды» |
| «Компании» | `companies` | компании; под ними «Убрать человека» (сколько держать ×: Сразу / 1 с / 1,5 с / 2 с) — тоже про людей | «Кто ест вместе» |
| «Популярные блюда» | `presets` | кнопка «Добавить популярные блюда»: около 30 простых и 20 составных рецептов с обычным весом, без тары; добавляются к своим блюдам в конец списка, блюда с таким же названием пропускаются; если в приложении уже есть блюда или готовки — сначала подтверждение; после добавления тост с «Отменить»; когда добавлять нечего, кнопка неактивна с подписью «Все популярные блюда уже добавлены» | «Готовые рецепты для начала» |
| «Копия данных» | `data` | «Скачать» / «Загрузить» JSON-файл; загрузка — после подтверждения, с «Отменить». Вошли — подтверждение говорит, что данные группы заменятся у всех её участников. Без аккаунта — подпись: «У приложения на экране „Домой“ iPhone своё хранилище… Проще всего войти в аккаунт и там, и там…» | «Скачать или загрузить файл» |
| «Оформление» | `appearance` | «Тема»: Как в системе / Светлая / Тёмная (по умолчанию — как в системе). Выбор запоминается в этом браузере и не попадает в копию данных | «Светлая или тёмная тема» |
| «Аккаунт» (этап 12, первым в меню) | `account` | Не вошли — «Данные только на этом устройстве. Войдите, чтобы данные были на всех устройствах и в общей группе.» и «Войти» → `#/account`. Вошли — почта, статус синхронизации (этап 13), «Добавить вход по Face ID» / «Face ID добавлен», «Выйти» (только с сетью; данные групп уходят с устройства, на сервере остаются) | Не вошли — «Данные только на этом устройстве»; вошли — почта |
| «Группа» (этап 14, только после входа) | `group` | Выбор группы (если их несколько) и ★ «Открывать при запуске»; название (правится на месте); участники (× удержанием — убрать, только владелец); «Пригласить»; «Вступить по коду»; «Выйти из группы» (не у «Личной») | Название открытой группы · N участников |

**Телефон (< 768 px):** `#/settings` — список подразделов (иконка, название, подпись, «›»). Тап открывает подраздел отдельным экраном: в шапке «←» обратно к списку и название подраздела. Нижнее меню остаётся на всех экранах настроек, «Настройки» в нём активны.

**Планшет и десктоп (≥ 768 px, `md`):** слева меню подразделов, справа выбранный подраздел, «←» в шапке нет. На `#/settings` справа открыт первый подраздел («Аккаунт», с этапа 12; до него — «Тара») и он же подсвечен в меню.

### Вход (`#/account`, этап 12)
```
│ ←  Аккаунт                          │
│ [ Войти | Создать аккаунт ]         │
│ Почта   [ vanya@example.com       ] │
│ Пароль  [ ••••••••                ] │
│ [            Войти              ]   │
│ [  ◉ Войти с Face ID            ]   │
│ Забыли пароль?                      │
```
- Поля: `autocomplete="email"`, `"current-password"` / `"new-password"` — iPhone предлагает и сохраняет пароль. В поле почты iPhone сам предлагает Face ID, если он уже добавлен.
- Без сети: после нажатия «Войти» — «Нет сети — войти можно, когда она появится».
- «Забыли пароль?» (пока нет писем): нужна почта в поле; под полями — «Ссылку для нового пароля пришлёт владелец приложения — напишите ему». По ссылке — экран «Новый пароль» (`#/account/reset`) → «Сохранить пароль» → тост «Пароль изменён — войдите с ним».
- Ошибки — под полем пароля, свои, по-русски (подсказки браузера выключены): «Пароль — не короче 8 символов», «Неверная почта или пароль», «Такая почта уже зарегистрирована», «Нет сети — войти можно, когда она появится», «Face ID не сработал — войдите паролем».
- После входа — в Настройки → «Аккаунт». Данные, которые были на устройстве без аккаунта, переезжают в группу «Личная»: молча, если в ней пусто; иначе `AlertDialog` «Перенести данные этого устройства?» → «Перенести» / «Не переносить». Копия данных устройства в любом случае остаётся в браузере.

### Аккаунт и группа (Настройки, этапы 12–14)
```
Аккаунт                               Группа
│ vanya@example.com                │  │ [ Личная ★              ⌄ ]   │
│ ✓ Синхронизировано · 19:42       │  │ Название [ Личная         ]   │
│ ◉ Face ID добавлен               │  │ Участники                     │
│ [ Выйти ]                        │  │ vanya · владелец              │
                                      │ ksusha                     ×  │
                                      │ [ + Пригласить ]              │
                                      │ Вступить по коду              │
                                      │ Выйти из группы               │
```
- «Пригласить» раскрывает на месте: код крупно (`K7MR-Q2XD`, моноширинные цифры), ссылка, «Копировать» и «Поделиться», «Действует до 13 окт.», у владельца — «Отозвать».
- Звёздочка у группы по умолчанию; у другой группы в списке — «Открывать при запуске».
- Переключение группы открывает список блюд этой группы.
- Статус синхронизации — одной строкой под почтой. Если нужно действие («Войдите снова…» — с кнопкой «Войти снова», «Обновите приложение…», «Нет доступа к группе»), на пункте «Настройки» в нижнем меню — точка цвета `--warning`. «Нет сети…» — обычный режим, без точки.
- «Выйти» из аккаунта: если не всё отправлено — «Не все изменения отправлены. Выйти всё равно?».

### Вступить по ссылке (`#/join/:code`, этап 14)

## 5. Десктоп (≥ 1024 px, `lg`)

Экран готовки — две колонки: слева «Сегодня», справа «Кто ест» (sticky). Список блюд, блюдо и редактор — одна колонка шириной ≤ 720 px по центру; настройки — меню подразделов слева и выбранный подраздел справа (уже с `md`, см. «Настройки» выше).
