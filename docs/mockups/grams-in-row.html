Вариант А: граммы в строке, с «Составом»

Полоса показывает доли шириной, граммы каждого — один раз, в его строке или контейнере. «− +» без имени: между кнопками — крышка выбранного, тот же цветной квадратик, что на полосе и у строки. Выбранная строка (или контейнер) подсвечена фоном, у её крышки — обводка. Тап по сегменту полосы, по строке или по контейнеру выбирает.

Кнопка «Состав» общая для всех телефонов, как в приложении.

Люди

Рецепт под каждым человеком. Число — только справа в строке.

Доли поровну

«по 790 г» и рецепт — один раз. Контейнеры — только номера.

Доли разные

Порции отличаются: граммы и рецепт в каждом контейнере, по два в ряд.

Что меняется по сравнению с PR #72

  • На полосе нет граммов: имена у людей, номера у долей.
  • Под полосой «− ■ +»: крышка выбранного вместо имени и граммов.
  • Выбранная строка или контейнер подсвечены; тап по строке тоже выбирает.
  • Доли поровну: контейнеры без граммов, «по 790 г» и рецепт — над ними один раз.
